# NLP Solver for Real-Time Wind Turbine Control - Implementation Guide

## Overview
This system solves a nonlinear optimization problem **online in real-time** to find optimal wind turbine control settings (rotor speed and pitch angle) based on current wind speed measurements. Instead of using lookup tables, it computes the optimal solution at each time step using the IPOPT solver embedded in compiled C code.

---

## Code Files Explained

### **1. compile_NLP_to_C_corrected.m** (MATLAB - You Run This Once)
**Purpose:** Generate optimized C code from the symbolic NLP problem

- Takes your turbine model, constraints, and objective function
- Uses CasADi to create symbolic math representations
- Compiles all derivatives and Hessians to C automatically
- Outputs: `nlp_solver.c` and `nlp_solver.h`
- **When:** Run once offline, never again

---

### **2. nlp_solver.c & nlp_solver.h** (C - Auto-Generated)
**Purpose:** Core IPOPT solver algorithm in compiled C code

- **nlp_solver.c**: Contains ~2000+ lines of pure C code with:
  - IPOPT interior-point solver implementation
  - Constraint evaluations
  - Objective function calculations
  - Derivative and Hessian computations
  
- **nlp_solver.h**: Header file that declares available functions
  - Tells external code what functions exist
  - Specifies function signatures and parameters
  
- **Status:** Do NOT edit - auto-generated by CasADi
- **Fate:** Gets compiled into `nlp_solver.dll` (Windows) or `.so` (Linux)

---

### **3. nlp_solver_dspace_wrapper.c & .h** (C - You Create)
**Purpose:** User-friendly interface layer between Simulink and the solver

- **nlp_solver_dspace_wrapper.c**: Contains:
  - `solve_nlp_realtime()` function - simple interface
  - Persistent memory for warm-start (faster convergence)
  - Error handling and fallback logic
  - Calls the low-level `nlpsol_F()` internally
  
- **nlp_solver_dspace_wrapper.h**: Declares the wrapper function
  - Simple signature: `wind_speed → [rotor_speed, pitch_angle]`
  - Easy for MATLAB/Simulink to understand

- **Input to function:** Wind speed (scalar)
- **Output from function:** Optimal rotor speed & pitch angle
- **Compilation:** Compiled together with `nlp_solver.c` into same DLL

---

### **4. solve_NLP_sfcn_realtime_dspace.m** (MATLAB S-Function - You Create)
**Purpose:** Bridge between Simulink and the compiled C solver

**What it does:**
- **initFcn()**: Loads `nlp_solver.dll` when Simulink starts
- **outputFcn()**: Runs at every simulation time step:
  - Reads wind speed from Simulink block input
  - Calls the compiled solver via `calllib()`
  - Returns optimal pitch and rotor speed to Simulink outputs
  - Implements dead-band checking (skip solve if wind speed barely changed)
  - Handles solver failures gracefully (uses previous solution as fallback)

- **Input:** Wind speed signal from your Simulink model
- **Output:** Two outputs: `Optimal_RotSpeed` and `Optimal_Pitch`
- **Execution:** Runs at each Simulink time step (e.g., every 10ms)
